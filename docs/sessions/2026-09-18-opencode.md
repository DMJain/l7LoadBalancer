## S1.T6 — Implement `internal/proxy` (issue 05 of `.scratch/s1-t3-t9-backend-selector-proxy/`)

### Goal
Wire the request lifecycle: `ServeHTTP` selects a backend, short-circuits a
503 when none are healthy, increments the chosen backend's active-connection
count, proxies via `httputil.ReverseProxy`, decrements exactly once when the
response completes (or the round trip fails), and emits one structured
"request complete" log line per request.

### Done
- `internal/proxy/proxy.go`: implemented `New` (builds `*httputil.ReverseProxy`
  once with `Director`/`ModifyResponse`/`ErrorHandler` bound to methods, and
  captures `slog.Default()`), and `ServeHTTP`:
  - calls `sel.Select` itself; `ErrNoHealthyBackends` → 503, any other
    selector error → 502, both before touching `ReverseProxy`;
  - on success calls `IncActive()` and attaches a per-request `reqState` to the
    request context through an unexported `reqStateKey`;
  - `Director` reads the state back and sets only `req.URL.Scheme/Host`;
  - `ModifyResponse` records `resp.StatusCode` and wraps `resp.Body` in
    `releaseBody`, whose `Close()` calls `state.release()`;
  - `ErrorHandler` records 502, calls `state.release()`, logs the transport
    error at WARN, and responds 502;
  - `reqState.release()` is `sync.Once`-guarded, so `DecActive` fires exactly
    once whether the body wrapper or the error handler (or, defensively, both)
    runs;
  - a single deferred `logRequest` emits "request complete" on every path
    (including the `http.ErrAbortHandler` panic path) with the canonical fields,
    WARN for 5xx, INFO otherwise.
- `internal/proxy/proxy_test.go` (new, Red first): distribution through a real
  front `httptest.NewServer` matches RoundRobin's a/b/c cycle; no-healthy →
  503 (empty registry and all-unhealthy table cases); non-sentinel selector
  error → 502 via a stub `errorSelector`; dead backend → 502 and `ActiveConns`
  back to 0; 100 concurrent in-flight requests (backend handlers blocked on a
  release channel) assert `ActiveConns == 100` while blocked and drain to 0
  after release; log assertions for one "request complete" line on the success
  (INFO + all six fields), 503 (WARN), and 502 (WARN + a separate WARN
  "backend round-trip failed" cause line) paths.
