  missing file (`errors.Is(os.ErrNotExist)`), invalid YAML, unknown field, field
  population, and "Load does not default".

  example from `docs/design/sprint-1-contracts.md`.
- Deleted `tools.go` (per ADR-0003) now that `config` imports yaml and its tests
  import testify for real; `go mod tidy` produces no diff.
- Verified: `make test`, `make test-race`, `go vet ./...`, `gofmt -l .` all

## Decisions
- No new ADR: every non-trivial decision (KnownFields strictness, error
  wrapping, fail-fast order, name charset, algorithm implemented-set, URL
  scheme/query/fragment rules) was already fixed by
  `docs/design/sprint-1-contracts.md` and the issue spec.
- Validation order implemented literally as specified: Listen → backends count
  → per-backend name/URL → name uniqueness → algorithm.
- Name uniqueness checked in a second pass so per-backend name/URL errors take
  precedence, matching the spec's stated order.
