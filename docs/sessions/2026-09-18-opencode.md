## Audit fixes (S1.T2-fix follow-up)

Two-axis code review of the S1.T2 diff (fixed point `3c87896`) surfaced
findings; this follow-up addressed the actionable ones, keeping the tree
green throughout.

- **fix(config): reject uppercase URL schemes** — the audit found a real bug:
  `url.Parse` lowercases `u.Scheme`, so `HTTP://host` passed the post-parse
  `http`/`https` check. Validation now requires a lowercase `http://` or
  `https://` prefix on the **raw** string before parsing; the host/query/
  fragment checks are unchanged. Two rejection cases (`HTTP://backend:9001`,
  `HTTPS://backend:9001`) added to the `TestValidate` table (written red-first).
- **test(config): assert example.yaml round-trips** — added `TestExampleConfig`,
  which reads `configs/example.yaml` from disk via a path relative to the
  package directory and runs `Load` + `Validate`, so the shipped example cannot
  drift out of sync with the schema.
- **docs(adr): add ADR-0004 rejecting unimplemented algorithms** — records the
  vocabulary-vs-acceptance distinction (`implementedAlgorithms` is the Sprint 1
  acceptance set), supersedes the frozen constant block's "all four accepted"
  comment, and is indexed in `AGENTS.md`. Rationale: validation encodes "will
  this work?", not "does this parse?".
- **chore: align tracking files** — corrected the PROGRESS S1.T2 Files bullet to
  the split test files, ticked issue 02's acceptance boxes, and completed this
  log's commit list (the missing `refactor(config): table-drive TestLoad cases`).
- **refactor(config): rename loop var and remove scratch reference** — `b` →
  `backend`; `config.go` no longer points at the ephemeral `.scratch/` spec,
  citing ADR-0004 instead.
- **Dismissed findings** (documented, not acted on): `errors.New` for leaf
  errors with no underlying cause (correct Go idiom; the AGENTS.md ban is for
  dynamic messages), and the `validateBackendURL` data-clump shape (not a
  Sprint 1 concern).
