## What was built

- `demo/control-service/main.go` — a stdlib-only Go program (its own small
  image, the traffic-generator precedent). It is **stateless**: no desired
  configuration is stored. `GET /api/state` reads the eight generators' status
  and the four admin listeners' profiles live; the active LB and total rate are
  derived and reported only when every generator agrees. Three actions —
  `POST /api/lb`, `/api/rate`, `/api/backend` — validate before any outbound
  call (`DisallowUnknownFields`, LB/backend membership, profile ranges), fan out
  concurrently to all eight generators (or forward to one admin listener), and
  name every failed peer in the response.
- `demo/control-service/page.html` — one embedded plain-JS page (`//go:embed`,
  no framework, no build step, no charting code). Switch LB, set rate, set each
  backend profile, show active LB / profiles / total rate / generator counters,
  show a failed action as failed, and embed three dashboard panels as iframes at
  `var-window=15s&refresh=5s&var-lb=<active>`.
- `demo/control-service/main_test.go` — an `httptest`-stand-in suite over the
  JSON API.
- `demo/control-service/Dockerfile`, `demo/docker-compose.yml` (a `control`
  service, `127.0.0.1:8095:8090`, internal peer URLs, no Docker socket),
  `demo/README.md` (published-port row + control-page section).

## Decisions

- **ADR-0025 written** (stateless read-through, honest fan-out). The spec fixed
  the actions and constraints; the state model — derive, never store — was the
  non-trivial decision the ADR records.
- **A peer's name is its URL hostname.** The compose service name is also the
  Prometheus `job` and the dashboard `$lb`, so one string carries identity, the
  fan-out target and the iframe variable; no separate mapping that could
  disagree with itself.
- **Read a backend profile with `POST {}`.** The admin listener is POST-only
  (S5.T16.1), so a read is the keep-all empty body — the same form
  `demo/acceptance.sh` uses.
- **Partial fan-out is a 200 with `ok:false` and the failed peers named.**
  A `502` would make every client treat it as a generic error and discard the
  detail the page must show.
- **Host port 8095, not 8090.** The bench stack's nginx already publishes host
  `:8090`; the demo and bench stacks are run one at a time but the port is kept
  free anyway. The control service's internal port stays `8090`.

## Review findings folded in (two-axis)

- Standards: de-duplicated the three concurrent per-peer loops into
  `forEachPeer`; `backendState`/`generatorState` now embed their peer-contract
  types; a named `backendUpdate` replaces the anonymous request body; the
  `client.Do` error is wrapped; the test file documents its concurrency model.
- Spec: peer-derived strings are set with `textContent` (no `innerHTML`); the
  page no longer resets a backend input mid-edit (the 2 s poll skips the focused
  input); the charts now follow the selected LB even when the generators are
  mixed, instead of keeping a stale `var-lb`.
- Not changed: an empty action body is a 400 (the actions have required
  fields), unlike the siblings' keep-all update endpoints — deliberate.
