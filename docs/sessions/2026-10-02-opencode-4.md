## Decisions

- **`lb` variable from `label_values(job)`**, per the issue: independent of any
  metric, so it resolves from the seeded gauges before traffic flows.
- **`current: {}` for `lb`**: Grafana selects the first option on load, which in
  the root stack is the single `l7loadbalancer` job, so every panel shows what it
  showed before.
- **`scalar()` denominator** for the share panel: `sum(rate(...))` with no `by`
  is one element; the alternative `on() group_left()` needs no scalar but reads
  worse. `percentunit` (0–1) matches "rate divided by the total".
- **`15s` included in the interval options** so the demo's `var-window=15s` is a
  first-class choice, not only a URL override.
