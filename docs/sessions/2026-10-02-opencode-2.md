## Decisions

- **Omitted field keeps its current value** (issue's recommended default):
  pointer fields on the request struct distinguish omitted from present-zero, so
  the control page can set one knob at a time. Pinned by
  `TestAdminOmittedFieldKeepsValue`.
- **Validate-then-store once**: the admin handler applies present fields onto a
  copy and stores only after every field validates, so a rejected request never
  half-applies a profile.
- **`newHandler` kept as a wrapper** rather than changing its signature: the
  prefactor's gate is "existing tests stay green unchanged", and it is the
  existing test seam. Production uses `newBackend` so the request and admin
  handlers share one profile pointer.
- **No ADR**: ADR-0023 decision 7 already fixes the design; this ticket only
  implements it.
