## What was built

- `demo/control-service/main.go` — an `engineClient`: the standard library's
  HTTP client against the Docker Engine API, no SDK. `DOCKER_HOST` (default
  `unix:///var/run/docker.sock`) selects the endpoint; a `unix://` host dials the
  socket with a custom `DialContext` and base URL `http://docker`, an `http(s)`
  host is used directly (the test seam). `POST /api/backend/kill` →
  `POST /containers/{name}/kill`; `POST /api/backend/revive` →
  `POST /containers/{name}/start`; both validate the backend against `BACKENDS`
  before any Engine call and address `CONTAINER_PREFIX + name` (default
  `l7loadbalancer-demo-`), never a caller-supplied name. `GET /api/state` reads
  each backend's Engine `State.Status` beside its profile. A failed Engine call
  is a `200` `{ok:false,error,container}` (ADR-0025 decision 4).
- `demo/control-service/page.html` — Kill/Revive buttons and a container-state
  span per backend, set with `textContent`.
- `demo/control-service/main_test.go` — an `engineStub` httptest stand-in for
  the three Engine endpoints, wired through `newRig`.
- `demo/docker-compose.yml` — `/var/run/docker.sock` mounted into `control`
  only; `user: "0:0"`; each backend pinned to `container_name:
  l7loadbalancer-demo-backendN`.
- `demo/README.md` — a Docker-socket section stating the socket is
  root-equivalent and acceptable only because every port is loopback.
- `docs/adr/0025-demo-control-service-model.md` — amendment, decisions 7–11;
  `docs/adr/INDEX.md` row updated.

## Decisions

- **ADR-0025 amended, not a new ADR.** Decision 6 had explicitly deferred the
  socket to S5.T16.4.2, so the engine model is an extension of the same ADR; the
  amendment records the stdlib-over-unix-socket choice, the derived allowlist,
  kill/start semantics, error shape, state read, and the root-user rationale.
- **`DOCKER_HOST` + an `http(s)` branch.** Docker's own env convention for the
  socket, and the `http(s)` branch is the httptest seam the ticket asks for —
  no interface or mock needed.
- **Explicit `container_name` + `CONTAINER_PREFIX`.** The allowlist is a stated
  string, not a name computed from the compose project/index.
- **Root only for the socket.** The scratch image's non-root user cannot open
  the root-equivalent socket; the demo is loopback-only, so root is bounded and
  honest (ADR-0025 amendment decision 11).
- **No state in the kill/revive response.** The page refreshes `/api/state`
  after every action, so the action response carries only `ok`/`error`/
  `container`; fewer Engine calls and one source of container state.
