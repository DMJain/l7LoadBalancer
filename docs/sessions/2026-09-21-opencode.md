## Decisions

- **Test `logger.New` as-is; do not add a writer parameter.** `New(level)` is
  a frozen Sprint 1 signature (S1.T0.5), and the ticket asks only for
  coverage. Adding an `io.Writer` parameter would be a contract deviation
  requiring an ADR for a test-only need. The `os.Pipe` swap observes the
  real production handler on the real production writer.
- **No new ADR.** The only choice here is a test technique, not a system
  design decision; it is documented in the helper's comment and above.
- **`require` for setup, `assert` for values**, matching every existing test
  package.
