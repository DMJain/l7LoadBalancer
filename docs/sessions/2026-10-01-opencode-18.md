## Done

- `bench/generate-results.sh` — three new functions plus a call:
  - `allowed_cells <doc>` parses only the generated regions and prints
    `unit<TAB>value` for the numeric cells of every Markdown table column whose
    header carries a `(ms)`, `(µs)` or `(req/s)` unit. Cells under a percentage
    or unit-less header are never emitted, so a percentage or raw count cannot
    satisfy a narrative figure.
  - `narrative_tokens <doc>` scans only outside the markers for
    `[≈~]?number[ \t]*(ms|µs|req/s)` behind a non-word boundary, strips the
    approximate prefix, commas and whitespace, and prints `unit<TAB>number<TAB>
    token`. The boundary means a percentile name (`p99.9`) or identifier
    (`ADR-0020`) is never matched; tabs in a token are normalised to spaces so
    they cannot split the TSV record.
  - `check_narrative <doc>` compares each token's unit and numeric value against
    a generated cell and, on any mismatch, prints a header plus every unmatched
    token and returns nonzero.
  - The check runs on the candidate document **before** `mv`, so a failed run
    leaves the existing document untouched (the `git_dirty` refusal is likewise
    pre-write). Header comment and `usage()` document the rule.
- `bench/generate-results_test.sh`: a new section writes a narrative exercising
  all four cases — matching (`0.277 ms`, `48,000 req/s`), `≈`/`~`-prefixed
  matching (`≈2.5 ms`, `~44000 req/s`), exempt tokens (`25%`, `ADR-0020`,
  `p99.9`, `1MB`, `48 runs`) — and asserts the run passes. It then rewrites the
  matching figure to `12345 req/s` and appends `≈12345 ms`, and asserts the run
  fails and both figures are named.
- `bench/README.md`: the *Results generator* section documents the check.
- `PROGRESS.md`: S5.T10.3 `[DONE]` with completion, acceptance and verification.

## Decisions

- **Unit-aware cells.** A generated cell is only a valid target if its column
  header names the same unit, so `2.5 ms` cannot be satisfied by a `2.5%` share
  or a `48000 req/s` peak cannot satisfy `48000 ms`. Percentages and counts fall
  out of the same rule.
- **Numeric, not string, equality.** `≈` signals an approximation, so comparison
  is on numeric value; `≈2.5 ms` matches the cell `2.500` and `48,000 req/s`
  matches `48000`. Commas are stripped on both sides so a future cell separator
  cannot break the match.
- **A non-word left boundary is the exemption mechanism** for percentile names
  and identifiers, which no amount of unit matching could otherwise exclude.
- **Validate before publishing.** The check reads the candidate file before the
  atomic rename, so a drifted narrative never rewrites the published document.
- **No new ADR, no Go, no harness change.** The spec fixes the approach; the
  generator is a benchmark tool.
