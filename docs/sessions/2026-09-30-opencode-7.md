## Decisions

- **`runtime.GOMAXPROCS(0)` reads the effective value**, not the raw env var: it
  is what the runtime actually schedules on, which is exactly the pinning claim
  the harness needs. `runtime.Version()` is the toolchain string the binary was
  built with.
- **Same log call, two fields.** The spec forbids a new statement; the line is
  already the one the harness parses for provenance.
- **No ADR, no collector.** Per the spec: no decision here is at once hard to
  reverse, surprising and a real trade-off.
