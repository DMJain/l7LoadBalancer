## Decisions without a dedicated ADR

- **`ErrNoHealthyBackends` is the only branchable sentinel.** The proxy uses `errors.Is` on it to choose 503 over 502. All other errors are wrapped. `ErrDrainWindowExpired` is a `context.Cause` comparison value, not a branchable condition (ADR-0016).
- **`httputil.ReverseProxy`, not a hand-written proxy.** It handles hop-by-hop headers, `X-Forwarded-For`, buffering and flushing. The project's own work is in selection, concurrency, resilience and lifecycle.
- **Round-robin index:** an `atomic.Uint64` counter, modulo the number of selectable backends. No mutex.
- **Least-connections tie-break:** the first backend in registry order among those with equal `ActiveConns`.
- **Least-connections scan:** a full scan of the selectable slice on every `Select`. No heap.
- **`golang.org/x/net/http2/h2c` is the one request-path dependency outside the standard library.** The stdlib cleartext HTTP/2 (`http.Server.Protocols` with `SetUnencryptedHTTP2(true)`, Go 1.24+) detects only the prior-knowledge `PRI * HTTP/2.0` preface. The h2c HTTP/1.1 `Upgrade` handshake needs `x/net/http2/h2c`. The package is deprecated but is still the only implementation of both modes. If the Upgrade mode is dropped, the stdlib path can remove the dependency.
