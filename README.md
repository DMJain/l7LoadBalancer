# l7LoadBalancer

A Layer 7 HTTP load balancer in Go.

**Status**: under active development. See `MILESTONES.md` for the sprint plan and `PROGRESS.md` for current state.

## Quickstart

```
make build
make run
```

The proxy listens on `:8080` and reads `configs/example.yaml`.
