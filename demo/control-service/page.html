Change the algorithm (hot reload)

  1. Edit demo/configs/lb.yaml and set algorithm: to round_robin, least_conn, consistent_hash or p2c_ewma.
  2. Send the reload signal: docker compose -f demo/docker-compose.yml kill -s HUP lb

The same process keeps serving: no restart, no dropped requests. The header above changes and the traffic-share chart gets a marker.
